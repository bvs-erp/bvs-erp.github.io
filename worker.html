홈 화면 바로가기 추가 안내

홈 화면에 추가하시면 매번 링크를 찾을 필요 없이 스마트폰 바탕화면 아이콘을 눌러 바로 출퇴근·작업일보를 열 수 있습니다.

1단계 브라우저 메뉴 열기 • 크롬: 화면 우측 상단 더보기 (⋮) 터치 • 삼성 인터넷: 화면 우측 하단 줄 3개 (≡) 터치
2단계 [홈 화면에 추가] 선택 메뉴에서 [홈 화면에 추가] (또는 [현재 페이지 추가] → [홈 화면])를 누릅니다.
3단계 [추가] 또는 [설치] 터치 팝업창에서 [추가]를 누르면 휴대폰 바탕화면에 BVS 데일리 아이콘이 생성됩니다.
1단계 사파리(Safari) 공유 버튼 Safari 브라우저 화면 하단 중앙의 네모+위로 화살표(↑) 공유 아이콘을 누릅니다.
* 카톡 등 인앱 브라우저는 우측 하단 점 3개 → [Safari로 열기] 먼저 실행
2단계 [홈 화면에 추가] 선택 공유 시트를 아래로 살짝 내려 [홈 화면에 추가] 항목을 터치합니다.
3단계 우측 상단 [추가] 터치 우측 상단의 [추가]를 누르면 아이폰 홈 화면에 전용 앱처럼 등록 완료됩니다.

        홈 화면에 앱 추가하는 방법
      
      
    


    
    

    

      스마트폰 바탕화면에 BVS 데일리를 추가해 두시면, 매번 주소창을 열지 않고 바탕화면의 앱 아이콘을 터치하여 바로 이용할 수 있습니다.
    


    
    

      
      
    


    
    

      

        1단계 브라우저 메뉴 열기
        • 크롬: 화면 우측 상단 더보기 (⋮) 터치
        • 삼성 인터넷: 화면 우측 하단 줄 3개 (≡) 터치
      

      

        2단계 [홈 화면에 추가] 선택
        메뉴에서 [홈 화면에 추가] (또는 [현재 페이지 추가] → [홈 화면])를 누릅니다.
      

      

        3단계 [추가] 또는 [설치] 터치
        확인 팝업에서 [추가]를 누르면 바탕화면에 BVS 데일리 아이콘이 생성됩니다.
      

    


    
    

      

        1단계 사파리(Safari) 공유 버튼
        Safari 화면 하단 중앙의 네모+위로 화살표(↑) 공유 아이콘을 누릅니다.

        * 카톡 인앱 브라우저는 우측 하단 점 3개 → [Safari로 열기] 먼저 실행
      

      

        2단계 [홈 화면에 추가] 선택
        공유 메뉴를 아래로 스크롤하여 [홈 화면에 추가]  항목을 터치합니다.
      

      

        3단계 우측 상단 [추가] 터치
        우측 상단의 [추가]를 누르면 아이폰 홈 화면에 바로가기 앱이 등록 완료됩니다.
